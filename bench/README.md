# Benchmark Gates

Raffel ships an official benchmark gate for the runtime hot paths that matter most
right now:

- HTTP front-door overhead
- HTTP route lookup (early and late exact routes under the same budget)
- Core router dispatch
- Shared-port protocol detection
- Front-door protocol rejection path
- Shared-port blocked-protocol rejection path

## Commands

Run the local suite against the current build:

```bash
pnpm bench
```

Run the CI gate against the existing build output:

```bash
pnpm bench:ci
```

## Budgets

Versioned budgets live in:

```text
bench/budgets.json
```

The file defines the current benchmark baseline contract and the minimum
`ops/s` allowed for each protected scenario. The exact-route lookup pair is
versioned with the same minimum budget so late registrations cannot quietly
degrade below the protected lookup floor.

## Results

The latest run writes a machine-readable report to:

```text
bench/results/latest.json
```

This file is generated by the benchmark runner and should be used to inspect the
current measured values when tuning budgets or investigating regressions.
